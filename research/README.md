# 研究语料索引

九篇深度检索报告，共约 592KB，176 条可访问来源 URL。
全部由 Perplexity `sonar-deep-research` 生成，统一要求：每条结论标注 A–E 证据等级、
菌株写到菌株号、剂量写清单位与疗程、法规写明文号与年份、没有定论就直说没有定论。

切块后共 **762 个知识块**，其中 **555 块带证据等级标注**，**115 块为法规内容**。

## 证据分级体系

| 等级 | 含义 |
|---|---|
| A | 人体随机对照试验的荟萃分析 / 系统综述 |
| B | 单个人体随机对照试验 |
| C | 队列研究 / 观察性研究 |
| D | 动物实验或体外实验 |
| E | 专家意见或机制推测 |

D、E 级结论在智能体里一律不得以肯定语气陈述，必须写明「证据不足」。

## 怎么用

重建索引（改了语料之后必须重建）：

```bash
.venv/bin/python -m agent.index build
```

新增一篇研究：

```bash
.venv/bin/python tools/research.py --ask <题目键名>
```

题目写在 `tools/research.py` 的 `QUESTIONS` 里。新增时保持同样的严格性要求
（证据分级、菌株号、剂量单位、法规文号、允许回答「没有定论」），
否则新语料的可信度会低于现有九篇，而检索层区分不出来。
